# 影视刮削

首版 `media-scraper 0.1.0` 要求宿主 0.3.10、API v2 和 `files.read`、`media.read`、固定 `scraper.service` 权限。在独立应用页面手动整理 TGDrive 网盘目录中的番号影片，通过 MetaTube 生成视频同目录的 NFO 与 JPEG 海报，供 Cinema 和飞牛影视客户端读取。

## 使用流程

1. 安装后选择允许整理与刮削的 TGDrive 目录；应用内再选择本次刮削目录，默认包含其子目录。
2. 在“后端连接”填写 MetaTube 地址，保存后检查连接。默认地址为 `https://metatube-server.hf.space/`，也支持自己的 HTTP/HTTPS 后端。
3. 勾选视频组。文件名无法唯一识别番号时手动填写；同目录同基本名的不同后缀视频按整组处理。
4. 点击“预览整理与刮削”，核对番号目录、同行字幕与资料、已有文件和候选。仅有一个番号精确匹配时自动采用；多个候选由用户选择。
5. 点击确认执行。散放视频移入当前父目录下的番号目录，已有同番号目录会复用，视频原名保留。默认补齐缺失 NFO、海报；已有专属和目录共用资料保留。
6. 在“操作记录”查看整理、NFO、海报各步骤结果。中断不明先核实，再手动继续未完成项；继续会重新预览。

主动重新刮削可分别选择 NFO 和海报。NFO 会整份覆盖其中的手工编辑内容；基本名不同的视频只更新选中视频的专属资料，目录共用资料保留。共用字幕或资料由用户在预览中选择同行，不会自动搬走。目标同名冲突、预览后改名、移动、内容或资料集合变化时，受影响项要求重新预览。

## 文件与展示

`ABC-123-4K.mp4` 生成 `ABC-123-4K.nfo` 和 `ABC-123-4K.jpg`。同基本名的 MP4/MKV 共用同名文件，必须整组选择，只写一份。不同基本名的视频共享选定作品资料，保持独立文件入口。

NFO 保存番号、标题、收到的原始标题、发行日期、完整简介、演员、导演、厂商、品牌、系列、分类、评分与来源。不自动翻译，缺失字段不编造；未知评分量表只存来源原始数值。生成与两端读取预算均为 1 MiB，超限明确标为待处理，不截断简介。

新海报为精确 2:3 JPEG，最多 2 MiB。消费侧优先使用 `基本名-poster.jpg/.jpeg`、基本名海报，再使用 `poster`、`folder`、`cover` 的共用海报；匹配忽略扩展名大小写。Cinema 1.5.1 读取标题、长简介和年份；含番号的电影关闭自动连播，不凭同目录位置自动播放下一版本或分段。飞牛服务仍沿用合计 3000 条视频的首期索引上限。

## 停止与恢复

首期只有手动执行。关闭页面、停止操作、撤权、停用和卸载会停止后续步骤；已完成的目录整理及资料保留。宿主重启不会自动续跑。单个已安装应用同时只能有一个写入批次；页面断线租约过期后不能继续提交。

在途步骤未到终态时显示“正在停止”，不能把请求中断视为已经取消成功。记录保留 30 天，清理记录不删除网盘文件。数据库备份或旧应用版本恢复所得记录仅供查看，必须重新扫描再创建新预览。

Token 只保存在宿主数据库旁的私有文件，页面仅显示是否已配置，不回读原值。Token 不进入数据库备份或应用恢复快照；更换后端或恢复后重新填写。卸载勾选清除应用数据时清除配置、Token 和记录。
