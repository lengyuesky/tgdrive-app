# 影视刮削

`media-scraper 0.1.3` 要求宿主 0.3.10 或更高版本。选择 TGDrive 网盘目录，点击一次“开始刮削”，即可连续处理整个目录及其子目录中的番号影片，生成 Cinema 和飞牛影视可读取的 NFO 与 JPEG 海报。

## 使用流程

1. 首次安装时授权可以整理和刮削的目录。只有一个授权目录时，应用会直接带入；也可点击“选择目录”更换本次范围。
2. 点击“开始刮削”。应用先读完目录分页，再逐个番号检查和立即写入；前面的影片无需等待整个目录的资料查询。无需选片、预览或确认候选。
3. 在页面查看当前视频、进度以及成功、跳过、失败数量。无法识别影片番号、没有同号匹配、文件冲突或资料归属不明确时直接跳过，结果中说明原因。
4. 保持页面打开。点击“停止刮削”或关闭页面会停止后续操作；已完成的结果保留。需要再次处理时，点击“重试未完成项”，应用会核实中断结果并按当前文件状态重新检查和补缺。

默认使用 `https://metatube-server.hf.space/`，后端地址和可选 Token 位于“设置”，保存一次即可。候选先按影片番号筛选，其他模糊结果不会挡住同号结果。同一番号的多个资料源代表同一影片，按后端返回顺序依次检查，使用首个可用详情；一个来源连接失败、返回 404 或资料不符时自动尝试下一个。同一批次的同号分段复用已采用来源。所有同号来源均不可用时记录具体失败原因。

搜索及详情的 HTTP 429、5xx、连接中断或超时最多自动重试一次；已有其他同号来源时先尝试其他来源，持续失败再处理下一影片。停止会取消重试等待。同号已有步骤提交后，后续分段固定使用已采用来源，避免中途换源造成资料混用。

## 整理与资料

散放视频自动移入当前父目录下的番号文件夹，已有同番号目录会复用；保留视频原名及各自播放入口。明确关联的字幕、同名资料随视频移动；归属不明确的共用资料不会自动搬走，受影响视频直接跳过。

默认补齐缺失 NFO 和海报，保留已有专属及目录共用资料。“设置 → 刮削选项”可显式开启重新获取并覆盖已有资料，分别选择更新 NFO、海报；NFO 会整份替换其中的手工编辑内容。重试未完成项始终按默认补缺执行。

`ABC-123-4K.mp4` 对应 `ABC-123-4K.nfo` 和 `ABC-123-4K.jpg`。同目录同基本名的 MP4/MKV 自动成组，共用资料只写一份；分段和不同基本名版本仍保持独立入口。

NFO 保存番号、标题、原名、发行日期、完整简介、演员、导演、厂商、品牌、系列、分类、评分和来源。保留后端语言，缺失字段不编造；未知评分量表保留原始值。NFO 上限 1 MiB，新海报为精确 2:3 JPEG、最多 2 MiB，超限不截断。

## 停止与记录

本应用由当前页面推进，没有后台调度；关闭页面、停止、撤权、停用和卸载都阻止后续步骤，宿主重启或重开应用不会自动续跑。扫描、匹配和写入期间都可停止；正在收尾的写入需要宿主确认停止后才能开始下一次任务。

无法匹配和文件冲突显示为跳过；查询、资料源或海报服务失败显示为失败。宿主确认当前单项已经收尾后，继续处理其余影片，已经写入的 NFO 和海报保留。真正提交结果不明、目录或授权改变、记录保存无法确认时停止整次任务，重试前自动核实，不能将网络中断当成文件尚未写入。

每次目录任务保存一条操作记录，包含全部扫描视频、具体来源错误和已完成步骤，关闭或重开后仍可查看。“查看旧版记录与执行明细”保留此前版本的记录。重试只处理当前仍在目录内的未完成视频；以宿主记录核对已提交结果，避免页面丢失回执后重复执行。

操作记录保留 30 天，清理记录不删除网盘文件。目录记录按大小分页存入应用私有存储，使用 revision 和写入标识确认保存；保存失败时停止后续操作。备份或旧应用版本恢复所得宿主记录仅供查看，需手动重新选择目录并开始。Token 只保存在宿主，回读显示配置状态；更换后端或恢复后需要重新填写。
