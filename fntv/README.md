# 飞牛影视服务管理插件

当前本地候选版本为 `0.1.0`，最低宿主版本为 `0.3.5`，使用 API v2 和固定 `fntv.service` 能力。它尚未加入公开插件目录。

安装包提供中文服务管理页，后台协议由宿主的受限能力执行。先在应用中心导入包，选择允许读取的网盘目录，再保存独立影视账号、创建命名的电影库或电视剧库，最后主动启动服务。官方客户端手动添加页面显示的服务根地址，不添加 `/fntv` 前缀。

关闭管理页后服务继续运行。停止、撤权、更换凭据、成功更新、停用或卸载会废止旧登录并中断相关传输。卸载默认保留服务数据，原网盘文件始终由宿主管理。该服务与 `cinema` 的库、收藏及进度独立，首期单用户。

视频按原字节及 HTTP Range 传输；首期根据文件名、目录和同目录 NFO、海报组织内容。媒体描述使用宿主的受限 FFprobe，读取后端须支持 MTProto 分段或已有的允许目录内本地缓存。解析失败会明确报告，不转码、不重封装、不完整缓存视频，也不联网刮削。

## 本地构建

使用 Node.js 22.22.0，在本仓库执行：

```sh
npm ci
FNTV_PACKAGE_OUTPUT=/path/to/local-output
npm run build:fntv -- "$FNTV_PACKAGE_OUTPUT"
```

独立命令只生成本地 `fntv-0.1.0.tgapp`，不更新公开 `catalog.json`、`SHA256SUMS` 和三款正式分发包。页面依赖 SDK 声明的 `fntv.service` 能力，不能仅凭 SDK 函数存在判断宿主支持。

本轮已通过包校验、类型检查、643 项插件测试及真实临时宿主管理页和程序接口验收。指定官方播放器连接完整宿主的最终复验因 Mac 锁屏未完成；此前独立合成服务的播放结果不作为本包的完整宿主验收。其他设备、HTTPS、4K/HDR 及未列出的播放组合分别验证。
