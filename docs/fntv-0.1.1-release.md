# 飞牛影视服务 0.1.1 公开目录发布验收

日期：2026-11-06，Asia/Shanghai。

飞牛影视服务 `fntv 0.1.1` 加入应用中心公开目录，最低宿主为 `0.3.6`。安装包、`catalog.json` 和 `SHA256SUMS` 同步提交，完整构建现在维护四款应用的最新包。首次安装先选择授权目录，再设置独立影视账号、创建媒体库并主动启动；客户端使用服务根地址。
