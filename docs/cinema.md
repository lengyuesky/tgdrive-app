# 影视应用

「影视」是应用中心的第四款独立插件（`cinema`，`1.2.3`，API v2）。在应用中心的「可安装」中安装后打开，或固定到侧栏。**不再默认扫描整个网盘**：先创建命名媒体库并绑定文件夹，进入该库后才加载视频。它不替换短视频，也不改变文件页的视频预览。

## 媒体库设置

1. 在首页或媒体库页点击「新建媒体库」，填写名称，例如「电影」。
2. 点击「选择文件夹」，选择 `/影视/电影` 等实际目录；一个媒体库绑定一个文件夹，自动包含其子文件夹。
3. 保存后返回媒体库入口；点击「进入媒体库」才加载该库的视频，不遍历其他库。可以分别创建「电影」「电视剧」等多个库。

- 首页只显示库名和绑定路径，不为数量或海报扫描目录；重新打开应用也停留在入口页，不恢复上次库的加载。
- 名称为去除首尾空白后的 1–50 个字符，不允许控制字符和重名。同一目录不能重复绑定，父子目录可以分别建库。最多 32 个库，整份配置最多 32 KiB。
- 必须明确选择文件夹，没有默认绑定目录。显式选择 `/` 时需额外确认“包含整个网盘”，取消确认不会保存。
- 「媒体库设置」支持改名、重新绑定和删除；删除仅移除配置，不删除原文件、收藏或观看历史。删除最后一个库后恢复建库引导。
- 目录按节点 ID 绑定，移动／重命名后继续定位原目录；路径只作显示缓存。删除或不可访问时提示重新选择，不误绑定同名新目录，也不回退根目录。
- 配置使用私有存储和 CAS 修订号；冲突保留表单草稿，读取云端最新配置后需要再次确认保存。读取失败或配置损坏时停止加载并提示重试。
- 从 `1.0.0` 升级后，旧 `source_dir` 不再自动启用或转成媒体库，需要手动建库；原有收藏、观看记录和播放偏好保留。旧的宿主单目录设置入口已移除。
- 构建不会替换正在运行的插件，请在应用中心主动更新影视到 `1.2.3`。新版按宿主能力启用票据直连读取与跨设备同步，封面行为不变，不改变媒体库、收藏和播放进度。

## 界面与功能

- 默认深色影院界面：媒体库入口、库内大封面和继续观看、收藏和历史；手机底部导航、桌面侧栏、横屏和沉浸播放。
- 文件名搜索和格式筛选只递归搜索当前媒体库，目录浏览仅展示直属节点，上一级不能越过该库根目录。每批最多 200 个节点，按服务器游标翻页，不受旧搜索 2000 项上限限制，不显示伪造的全库排序。
- 详情展示原文件名、路径、格式和大小；同目录合集按自然集数排序，识别 `S01E02`、`E02`、`第02集`。选集每批显示 100 项，目录最多整理 10000 个节点；超限显示警告并禁止自动连播，使用媒体库目录分页继续查找。
- 播放、暂停、进度拖动、前后十秒、音量、0.5–2 倍速、适应／填满画面、上一集／下一集、字幕、音轨、全屏、支持设备上的画中画。MKV 暂停后拖动或切换音轨仍保持暂停。默认同目录顺序连播，结束后五秒倒计时，可取消，不循环；详情尚未整理完成就点击播放，也会继续加载完整选集。
- 空格暂停，左右方向键快进退，上下方向键调整音量，M 静音，F 全屏。仅在播放器焦点区域生效，输入框和按钮自身的键盘操作优先。Tab／Shift+Tab 在播放器控件内循环，不落到背后的片库；退出恢复片库交互与焦点。手机左右区域双击快进退，忽略多指和拖动。
- 全屏按标准全屏、iOS 原生视频全屏、页面沉浸降级；始终保留返回入口。安全区由宿主统一处理。

## 播放格式：转封装不是转码

| 类型 | 行为 |
|---|---|
| MP4/M4V/MOV、WebM、OGV | 优先浏览器原生播放；实际支持取决于容器和编码。可识别的 MP4/MOV/WebM 会在点击播放后检查音视频编码 |
| MKV 的 H.264＋AAC | 客户端解封装并输出分片 MP4，通过 MediaSource 边读边播，支持索引定位和音轨选择 |
| HEVC、VP9、AV1、Opus 等 | 根据实际编码及浏览器 `canPlayType`／`MediaSource.isTypeSupported` 检测，不承诺所有设备可播 |
| AVI、WMV、FLV、TS/M2TS 等 | 会在媒体库显示，可尝试原生播放；首版不提供专门转封装保证 |
| DRM、加密或浏览器不能解码的轨道 | 清楚提示并提供下载，用本机播放器观看；不做重新编码，不自动忽略不支持的音轨 |

媒体模块固定使用 `mediabunny@1.56.1`，随包携带许可证，仅使用纯 JavaScript 容器处理，不访问 CDN，不加载 WASM，不启用 Worker、WebCodecs 编码器或外部网络源。

**不需要服务器 FFmpeg，也没有服务器转码、转码缓存或后台全盘扫描。** 下载入口下载的是原文件，不是浏览器转换后的文件。MKV 转封装需要 MediaSource；部分 iPhone／iOS PWA 的能力与桌面不同，缺少能力时正常降级下载。

### 读取与内存边界

- 媒体库入口页只读取配置；进入库后才查询视频。库内页面和详情不读取原视频，只读取元数据、封面和已有缩略图。点击播放后才签发原视频用途的请求。
- 收藏／历史仅分页读取已有私有记录，以有界 `files.stat` 校验当前路径，不递归搜索目录，也不为凑满一屏翻遍历史；过滤后为空的页仍保留下一页。列表只加载已有缩略图，不枚举父目录找海报。
- 单次 SDK Range 不超过 1 MiB；全应用字节调度最多四并发、每秒八次，为 SDK 控制消息留余量。原生 `<video>` 使用既有签名 Range 媒体地址，不经过这条 JS 字节队列。
- 影片块缓存最多 24 MiB、容器库缓存最多 8 MiB；探测／定位读取预算 16 MiB。不会将整部电影读取为 Blob 或回退整片下载。
- MSE 前方目标缓冲三十秒、后方十秒，移除已播数据；输出写入串行化，单分片和关键帧间累计数据不超过 16 MiB。超限／浏览器配额不足时停止并明确提示。
- 缺少可靠索引的 MKV 不进行整片扫描来提供拖动；从头播放，禁用随机定位并提示限制。
- 切片、拖动重建或退出时取消旧输入／数据泵，暂停并清空播放器 `src`、调用 `load()`，释放对象 URL。失效回调不得覆盖新影片。

## 本地封面与命名

推荐将一部电影或一个季度放入独立目录，例如：

```text
/影视/星际旅程/
  星际旅程 S01E01.mp4
  星际旅程 S01E01.zh.srt
  星际旅程 S01E02.mkv
  poster.jpg
  backdrop.jpg
```

海报优先采用视频同名 JPG/PNG/WebP，再采用同目录 `poster`、`cover`，然后使用网盘已有视频缩略图；横幅优先 `fanart`、`backdrop`。没有图片时显示根据片名生成的渐变占位，不使用外部资料或虚构评分、简介。

卡片图片按视口懒加载；已加载的封面在当前页面保留，滑出再滑回不重复请求，翻页或离开页面才释放图片节点和对象地址。未完成的离屏请求会取消，快速来回滚动不会重复启动同一卡片的加载。会话内仅缓存成功加载的封面，最多 150 项、本地封面字节合计不超过 32 MiB；缓存淘汰不撤销仍在显示的图片地址。

宿主支持封面库（能力 `covers`）时，首次加载成功的海报按长边 480 像素（横幅 1280 像素）压缩为 WebP 写入服务器封面库；
之后任何设备、任何会话打开都直接显示，不再读取原图或申请缩略图票据，只核对视频仍在媒体库范围内。
记录绑定视频内容版本、路径和同目录海报候选，替换或新增海报后自动重新生成；收藏和历史优先复用已存海报，其次缩略图。
封面库每应用上限 256 MiB，超出自动淘汰最久未看的封面，可在网盘「应用中心 → 设置」清理。旧宿主仍只用会话内缓存。

目录封面初次从直属节点第一页发现，打开详情整理完整目录后可发现后续封面。建议封面位于独立影视目录，不依赖巨型混合目录的封面自动发现。单张本地封面不超过 8 MiB、1600 万像素，解码前验证尺寸；不执行 SVG。

## 字幕

- 自动发现同目录同名和语言后缀的 SRT、VTT、ASS；默认 UTF-8，可手动切换 GB18030／GBK。
- MKV 内嵌 UTF-8、ASS、SSA 文本轨由有界 EBML 模块按播放窗口提取，支持选择及拖动后的重新定位。
- ASS 仅保留文本、逗号和换行，不还原字体、位置、动画或特效。不执行字幕 HTML，不提取附件字体。
- 字幕开关、大小 14–40、时间偏移 ±10 秒；使用 TextTrack 显示，以兼容原生视频全屏。
- 外挂最多 8 MiB、50000 条。内嵌窗口约为当前位置前十五秒至后四十五秒，最多检查六十四个 Cluster、十万个元素；无索引时不为字幕扫完整片。
- PGS/VobSub 图片字幕及烧录不支持，字幕错误不会阻止正常视频播放。

## 数据保存

只申请 `files.read`、`media.read`。收藏属于影视插件私有数据，不改变网盘的全局收藏。

- 媒体库配置 `media-libraries`（`schemaVersion: 1`）、历史 `progress:<节点ID>`、收藏 `favorite:<节点ID>`、偏好 `preferences`，使用宿主 SQLite 私有存储和既有备份机制，无新增数据库迁移。
- 收藏和历史只显示所有有效媒体库范围内的视频；库内继续观看只取当前库。文件移出范围、删除媒体库或改绑文件夹只隐藏记录，重新纳入后可恢复显示；无媒体库时不显示视频记录。
- 打开详情、播放、切集、收藏和下载前重新检查文件当前路径，旧记录不能绕过范围限制。父子库同时匹配时，从全局记录进入最深的匹配库。媒体库是影视应用的展示和操作范围，不改变宿主文件权限。
- 跨设备配置在重进页面、刷新及后续播放操作时重新读取，不新增后台轮询。
- 所有设备共用同一网盘实例中的数据。进度在成功读取历史并恢复位置后才保存；播放中最长每五秒保存，暂停、切集和主动退出及时保存。
- 达到 95% 或播放结束标记已看完，再次打开默认从头观看；未完成提供继续观看和从头播放。
- 移动／重命名按节点 ID 更新路径；内容版本改变不复用旧进度；不可访问的记录暂不显示。“清空历史”需要明确确认，包含库外隐藏记录，不删除收藏或媒体库配置。
- 进度 CAS 冲突需要选择「采用云端」或「保留本次」，不以最大播放秒数覆盖另一设备。读取历史失败时暂不保存，避免覆盖未知记录。
- 偏好冲突读取最新云端值并提示重新调整；不静默覆盖。存储容量不足提示清理历史，不自动删除收藏。
- 主动离开使用宿主最多两秒的退出保存握手；强制关闭浏览器只保证最近一次成功保存，不承诺离线同步。
- 卸载默认保留数据，显式选择清除应用数据才删除媒体库配置、历史、收藏和偏好；原文件始终保留。

## 开发与验证

```bash
npm run check
npm test
# 先在获授权的宿主工作区构建 frontend；两端写入和其他夹具停止后才运行集成测试
TGDRIVE_HOST_DIR=/path/to/tgdrive PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chrome npm run test:e2e -- cinema-libraries.spec.ts cinema.spec.ts cinema-lifecycle.spec.ts cinema-art.spec.ts
```

本仓库独立构建会产出 `apps/cinema-1.2.3.tgapp`，宿主及其 Docker 构建不再编译或携带插件。构建不自动安装到正在运行的网盘。标准包限制保持 16 MiB 压缩／32 MiB 解压／8 MiB 单文件。

浏览器测试沿用隔离网盘、临时数据库和内存 Telegram。FFmpeg **只用于测试合成**色块、测试音、双音轨 MKV 和中文字幕，不成为生产运行依赖。测试不加载真实 `.env` 或网盘。

自动化包含 MP4 续播、VP9＋Opus WebM 原生播放、实际 MKV 转封装／拖动／音轨切换／内嵌字幕、暂停状态保持、快速打开详情后播放、键盘焦点、手机布局、缺少 MSE 和损坏格式降级。原片请求计数从打开首页之前开始，覆盖首页及详情不读原片的约束。单元测试覆盖自然集数、字幕清洗及超限、Range 限流缓存取消、CAS 冲突、SDK 路径／稳定引用兼容，以及超过 2000 项的目录分页、10000 项整理上限和旧目录响应不能覆盖新缓存。

iOS Safari／PWA、Android Chrome 的编解码、全屏、画中画、安全区与内存仍应进行真机验收。桌面 Chromium 和视口模拟不替代这些真机检查。

命名媒体库自动化另外覆盖真实建库／编辑／删除、根目录二次确认、无库零枚举、库间查询隔离、目录节点移动与同路径重建、库外记录隐藏恢复、旧详情不能播放或下载移出文件、CAS 草稿保留、慢查询取消、配置读取失败、旧版升级及管理表单的小屏布局。保存和搜索直接通过 SDK 执行，回车不会触发原生表单提交，不需要放宽沙箱的 `allow-forms` 或 CSP。
