# 短视频 2.0.0

应用 ID 保持 `shorts`，清单采用契约 1.0，包目标为 `web`，没有应用后端，只申请网盘只读权限。入口为 `shorts/page/index.html` 和 `page/main.ts`，交互在 `app.ts`，随机浏览策略在 `queue.ts`，设置与收藏在 `state.ts`。页面 SDK 与共享样式/图标分别来自 `@tgdrive/page-sdk`、`@tgdrive/ui`，不再注入旧全局 SDK。

## 保留的界面和播放行为

- 维持深色全屏播放器、顶部返回/取材目录、右侧图标操作、底部标题和进度条；手机保留上下滑，桌面保留上下按钮、滚轮和键盘。
- 封面与视频地址独立请求，迟到封面不阻塞首帧、不覆盖切换后的视频；只有原文件有缩略图附件时才签发 thumbnail 票据，不让宿主提帧或识别格式。
- 播放开始后只预取下一条地址，最多保留一个，30 秒内且未接近票据过期时复用。不创建隐藏播放器、不提前下载下一条视频。
- 拖动进度暂时暂停，结束只恢复原来想播放的视频；手动暂停后静音/前后台切换不会改成自动播放。
- 保留自动播放被拒绝提示、格式错误提示、同条重试、跳过、下载、滚轮惯性一次一条、触摸多指/取消/横向手势过滤及尾随轻点抑制。
- 退出取消取材和媒体读取、清空 src/poster、解绑事件。沉浸、纯黑背景、标题、目录选择/授权、取材任务/取消、主题和关闭前保存走 `tgdrive.ui.v1`。
- 新的“取材与收藏设置”属于应用页面，不打开旧宿主设置；播放器固定深色，设置/文件信息面板跟随宿主主题。

浏览器解码能力决定支持的容器和编码；不提供转码。清单后缀为 MP4、MOV、M4V、MKV、WEBM、AVI、WMV、FLV、TS、MTS、M2TS、3GP、OGV，不声明目录打开方式。

## 随机取材，不遍历网盘

每次只调用 `files.random` 抽样最多 32 条，在所选目录 ID 或全部当前授权目录内筛选视频后缀。没有旧的 search/searchPage、全盘列表、2000 项截断、随机 OFFSET 或先遍历再洗牌。“洗牌”重新随机取材，而不是只打乱已经加载的小队列。

近期排除最多 512 个节点 ID，已有排队项与近期集合的并集仍遵守该预算。回看保留最多 100 条已走过的队列前缀，未来队列按需续填；续填在途只使用一个共享业务任务，最后一次切换意图优先，不是额外 HTTP 请求队列。小库全部落入近期排除时，使用另一份明确的业务筛选允许回看，不盲目重试同一 HTTP 请求。

启动取得变更检查点，SSE 提示后按 `files.changes` 核对取材范围，普通删除保守失效；变更续页只看 `has_more`。相关变化在下一次切换重新随机取材，无关来源变化不打断当前播放；授权变化立即清空当前媒体并重新读取范围。日志过期/同步提示重新核对，没有持久阅读索引。

来源锚定目录 ID，路径只作显示和即时取材范围核验；目录移动仍跟随身份，不在失效时退回全盘。选择目录不等于授权，只有实际读取被拒绝时请求主人确认。起播前 stat 当前节点与取材目录，再签发相同内容版本的票据。

从文件打开时直接播放已获授权的启动文件，并临时取材其父目录，不写入持久来源设置。点应用收藏也采用同样的临时取材方式，仍需当前授权；不会因为当前设置指向另一目录而丢失收藏。

## KV 数据设计

| 键 | 内容 |
|---|---|
| `shorts:data-version` | 当前应用数据布局版本 1，absent 条件初始化；未知版本停止启动，不覆盖。 |
| `shorts:settings` | `{schemaVersion:1,source,muted}`。source 为 `{type:"all"}`，或 `{type:"directory",id,path}`；只读默认取材全部当前授权目录、静音播放。 |
| `shorts:favorite:<节点ID>` | `{schemaVersion:1,id,contentVersion,name,path,addedAt}`，节点 ID 为规范十进制字符串；名字、路径和版本是收藏时的显示信息，不授予文件访问。 |

设置使用读取到的修订 CAS；新增收藏用 absent，已有记录更新用 revision，取消收藏只以修订删除。没有跨键事务、无条件 set/delete、宿主应用设置、网盘收藏或旧数据迁移回调。未知记录/读取失败不构造空基线写回；冲突重读当前状态，不自动覆盖。收藏列表按 KV 游标分页，每页最多 20 行 DOM，只有没有下一页游标才结束。

文件字节由浏览器通过媒体票据 Range 读取；应用不把整段视频变成 Blob。票据是以 `/` 开头的同源相对路径，直接给 video/img/下载，不拼接绝对宿主或服务基址。派生封面没有生成，所以短视频不额外使用小对象缓存；原附件表示由宿主管理。

## 相对旧版移除的功能

- 移除“在文件中显示”/网盘定位按钮，界面通道没有此能力。
- 移除宿主文件详情调用，保留应用自己的当前文件信息。
- 不再打开宿主应用设置或操作网盘收藏，改为应用内设置与自己的收藏列表。
- 不读取或迁移旧平台设置/收藏/数据版本；不保留旧 SDK、searchPage 或兼容降级层。

## 构建和回归

```bash
fnm use 22.22.0
npm ci
npm run typecheck
npm test
npm run test:shorts
node tools-v1/build-pages.mjs shorts "$NEW_OUTPUT"
```

`NEW_OUTPUT` 是仓库外的新目录，工具实际执行 `tgapp pack` 与 `tgapp verify`。页面依赖随包编译，第一方复制已声明的根 MIT LICENSE 与 SDK NOTICE，不新增代码许可头，不依赖 CDN，不修改已有发布资产。

原 `tests/unit/shorts.test.ts` 的全部 16 个用例保留其行为目标并移入 `shorts/app.test.ts`：播放、迟到地址、封面、预取、拖动、前后台、错误、键盘/滚轮、退出、长期队列和最后切换意图。旧“2000 项分页”改测超过 2000 个视频长期随机切换与有界队列；旧路径提示事件改用真实内存变更游标核对。另补万文件随机抽样、目录授权、KV/CAS/ABA、应用收藏分页、主题、关闭保存、取消和触摸回归。查询、授权与条件数据用 `@tgdrive/test-host`；只隔离媒体解码、界面回复和故障注入。

依赖旧全局 SDK 与退役入口的短视频浏览器夹具已删除。当前短视频只有 Vitest/测试替身自动化，尚无可运行的真实浏览器层自动化；不能把旧浏览器记录或当前单测计为真实宿主端到端通过。联调仍须确认真实 iframe/CSP/CORS、相对票据 URL、Telegram Range/取消、票据过期与重试、Scope/SSE 恢复、关闭期限、下载、手机触摸/旋转、实际自动播放与不同编码的浏览器兼容。包大小、摘要和重复构建结果以最终交接报告为准。
