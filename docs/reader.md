# 统一阅读馆

当前分发阅读馆为 `reader 1.1.0`，要求宿主 `0.3.3`。官方分发 `shorts`、`reader`、`cinema`、`fntv` 四款。书库由用户手动命名并一库绑定一个目录，在对应书库内浏览 TXT、EPUB、PDF、CBZ、ZIP 和图片目录。`books/`、`comics/` 的底层解析器源码和回归保留，独立官方分发入口退役。

1.0.5 同步公共 SDK 的可选飞牛服务接口，阅读页面及资源延续 1.0.4，升级保留书库、分组、进度、书签和自定义偏好。本次集成与目录校验见 [公开目录发布记录](fntv-0.1.1-release.md)。

## iPhone 主屏幕界面改版（1.1.0）

以 iPhone「添加到主屏幕」独立窗口竖屏为首要目标，iPad 与桌面沿用侧栏和悬浮工具栏，只换新视觉。共享规范见 `ui/base.css`（`--tg-*` 变量与 `.tg-*` 组件）和 `ui/icons.ts`，阅读馆改版样式集中在 `reader/mobile.css`。

- **两层全屏**：手机（`(max-width: 768px), (pointer: coarse)`）打开即请求宿主 `ui.setImmersive`，书库界面也不显示主站外壳；阅读时再隐藏插件工具栏，点屏幕中间 40% 唤出。宿主扣除安全区并用插件传来的 `--bg` 填色，插件内不叠加 `env(safe-area-inset-*)`。
- **翻页**：分页模式下正文跟手平移，松手超过宽度 18% 或快速轻扫即翻页，否则回弹；点左右各 30% 区域翻页。距左右边缘 20px 内起手的横滑留给系统返回手势。滚动模式仍可在“翻页方式”里切换。
- **工具栏**：顶部为返回、书名、快捷书签开关和“更多”；底部为可拖动进度条（两端上一章、下一章）及目录、主题、排版、翻页方式四个图标。书签列表、下载、作品详情、从头重读、目录设置、返回网盘收在“更多”里。同步状态只在失败时出现。
- **排版两级**：一级为字号 A−/A+、字体、紧凑/标准/宽松三档行距；“更多设置”展开原有全部细项。旧的精确行距值原样保留，正好等于某档时高亮该档。四种主题为跟随主站、明亮、护眼、深色。
- **常驻信息**：工具栏隐藏时显示淡色章节名与进度，可在排版面板关闭。
- **读完卡片**：只在真实末端出现；层级低于面板遮罩，打开“更多”、排版等底部面板时随正文一起被遮罩盖住，不挡面板按钮。
- **漫画**：未手动设置的作品按图片比例自动选择，长条漫（多数页高超过宽的两倍）进入连续滚动，普通漫画保持单页；用户改过的模式按作品记住。
- **书库（手机）**：保留首页 / 书库 / 我的三个底部标签，取消左上角抽屉；顶栏只留标题和搜索，书库页顶部为横滑筛选标签（全部与各书库，非手动书库模式还有类型、格式、分组），选中标签即表示当前书库，重复的标题区隐藏。“目录设置”“返回网盘”放在“我的”顶部。
- 从 1.0.5 更新为普通同 ID 升级，书库、分组、进度、书签与偏好不迁移、原样保留。

## 混合内容与阅读偏好

同一应用按文件真实格式选择文字、PDF 或漫画解析器；作品内容种类仍为 books/comics，不能把这些数据种类批量改为 reader。书库内可按类型、格式、分组和阅读状态筛选；“目录全部文件”只查询当前书库目录及子目录，不聚合其他书库。书签、阅读进度和偏好属于 reader 的应用私有存储。

阅读馆首装无偏好时，文字默认分页、漫画默认单页并适宽、PDF 默认适页；手机进入正文时隐藏工具栏，桌面初始显示悬浮工具栏。已有自定义模式、缩放和作品覆盖继续生效。1.0.1 的 V2 “单页＋整页＋100%”默认组合会以原修订号 CAS 迁移一次为适宽，保存 `comicWidthDefault: 1` 防止之后用户主动选择整页又被修改；其他格式和作品记录不变，冲突不自动覆盖。旧 flat/V1 仍只在内存映射。原 books/comics 的滚动回归继续通过显式偏好或独立解析器夹具保留。

## 手动目录书库与铺满宽度（1.0.2）

- 首页和“全部书库”只显示用户创建的书库；不自动生成图书、漫画或格式分类书库，不采用旧来源，也不把宿主目录授权当成书库。
- “创建书库”需填写名称并绑定一个目录，确认后立即扫描该目录及子目录，将独立索引保存到 `library:cache:shelves:v1:index:source:<nodeId>`；配置保存在 `library:shelves:v1`。创建前不枚举或显示网盘图书，从文件打开也不会自动创建父目录书库。
- 点击书库只显示对应目录的图书与漫画，切换会重置旧搜索、状态、分页和滚动位置。每库最多 2000 项整理索引，切换只驻留一份；超过上限可使用“目录全部文件”进行同目录的宿主分页查询。
- 最多 16 个书库，名称和绑定目录均不可重复；根目录另需确认。书库管理支持改名、重新扫描与删除绑定，删除不清除网盘文件、进度或书签。
- 重开应用先显示书库列表，不自动扫全盘；进入书库复用可用索引，显式刷新及相关文件事件只扫描当前目录。目录身份核对不依赖 JSON 键顺序，避免缓存被误判失效。
- 手机点左上角菜单打开同一书库侧栏，支持关闭按钮、遮罩、ESC 和 Tab 焦点循环；抽屉打开时背景不可操作。
- 漫画内边距为零，菜单悬浮且显隐不改变正文尺寸；桌面和手机通过宿主声明的 `ui.setImmersive` 请求全屏，返回书库恢复宿主界面。
- 默认等比例铺满视口宽度，小图也会放大；高图不因屏高缩小，超出的高度可上下滚动。手动选择整页时保持完整画面及必要空白；不拉伸、不裁剪，两轴共同受 CSS 尺寸上限约束。

手动目录书库与适宽行为的 1.0.2 验收见 [1.0.2 发布验收记录](reader-1.0.2-release.md)。[1.0.1 发布验收](reader-1.0.1-release.md)、[全屏与侧栏独立验证](reader-layout-validation.md) 和 [1.0.0 集成验证](reader-validation.md) 保留为历史记录。

## 书库紧凑布局（1.0.3）

- 手机端默认收起内容类型、格式、阅读状态、排序与分组筛选，点“筛选与分组”展开；非默认条件显示数量，收起不会清除条件。
- “重置筛选”清除类型、格式、状态、分组和排序，但保留当前手动书库及搜索词，不扩展到其他目录。
- 管理分组和“目录全部文件”位于展开面板；作品/文件切换始终可用。“批量分组”收起面板并显示独立移动栏，退出后恢复紧凑布局；只展开或收起面板不清空已选书籍。
- 书库名称与目录路径合并为紧凑标题区；手机顶栏使用有无障碍名称的设置、返回图标，点击区域仍不少于 44px。桌面筛选直接显示，改变视口时同步切换布局。

从 1.0.2 升级保留已有手动书库、分组、阅读进度、书签与自定义偏好，不要求重新创建书库。本版四张正式截图、真实旧包升级与完整本机集成结果见 [1.0.3 发布验收记录](reader-1.0.3-release.md)；升版前的独立验证保留于 [紧凑布局验证](reader-compact-layout-validation.md)。

## iOS 漫画滚动瞬跳（1.0.4）

- 图片尺寸变化完全被占位补偿吸收时直接保留实时滚动坐标，不再把原生滚动在重排期间推进的距离回写到旧锚点。
- 删除旧挂载节点、安装探测尺寸和整图尺寸修改前先保护滚动范围；测量完成后统一还原占位，避免章节末尾换窗时浏览器先截断坐标、再触发纠偏。
- 保留原生触摸与松手惯性、尺寸探测和估高学习、五页挂载、四十一页局部轨道与有界预读；显式跳页、书签和旋转后的页内比例恢复不变。
- 从 1.0.3 更新不重建书库，不清空分组、进度、书签或自定义偏好。源码复现与独立验证见 [滚动修复验证](reader-ios-scroll-validation.md)，本版发布门禁见 [1.0.4 发布验收记录](reader-1.0.4-release.md)。WebKit 回归不代替实体 iPhone Safari/主屏幕验收。

## 旧应用替换与清理

宿主 0.3.3 的安装预览会列出阅读馆替换的已安装旧图书/漫画应用，并说明应用私有数据清理范围。确认替换后，旧应用的进度、书签、偏好、书库配置及恢复快照会清理，不会自动迁移至 reader。网盘原文件及网盘收藏继续保留；取消安装不会执行替换或清理。需要替换的应用必须单独确认，普通批量更新不承担这一清理动作。

安装前请保留自己需要的旧进度与书签记录；确认后在阅读馆手动创建书库并绑定目录。仅从 catalog 移除旧包不等于旧应用数据已经迁移，不能把保留解析器源码描述成跨 ID 无损升级。

已经安装 `reader 1.0.2/1.0.3` 的用户更新到 `1.0.4` 会保留当前手动书库及分组，无需重建。安装 `reader 1.0.0/1.0.1` 的用户也可直接更新到 `1.0.4`；同 ID 更新保留应用记录，但旧 `library:sources` 不会成为手动书库。真实 1.0.1 升级验收中，用户重建同目录书库后旧进度和书签继续可用；自定义偏好保留，仅上述旧默认组合迁移为适宽。这与首次替换 `books`、`comics` 的清理行为不同。

## 构建与验证

`build.mjs` 构建 shorts、reader、cinema、fntv。reader 包同时携带 ZIP、DOMPurify、PDF worker、cmaps、standard_fonts，以及 ZIP/DOMPurify/PDF.js/core-js 和字体许可、NOTICE。不得依赖旧 books/comics 安装包或远程 CDN。SDK 改动若改变其他插件归档摘要，必须按同版本不可变规则检查并协调升版。

`npm test -- tests/unit` 验证四款分发、reader 清单版本、资源许可、退役包清理和同版本防篡改；所有分发构建使用合成临时输出，不依赖根目录已有 reader 包。`npm run test:readers` 使用真实 reader 入口与内存 Drive，保留书/漫内容夹具，新增 390/1280 两视口混合阅读切换。`npm run test:comics` 继续直接回归底层漫画几何与滚动。

跨库用例位于 `tests/browser/`，通过 reader 应用 ID 验证同库全部格式、移动阅读、来源、全库索引和平台集成。仅用显式 `TGDRIVE_HOST_DIR` 指向获授权宿主，使用临时数据库、内存 Telegram 与合成媒体；同一时刻只能有一个服务占用 4187。Cargo 默认复用该宿主的 target 目录。截图只写测试产物，最终源码截图由维护者独立生成。

每次迭代构建使用新的空 `TGDRIVE_APP_BUILD_OUTPUT`；真实截图完成后才生成最终根目录分发资产，不清除已发布基线绕过保护。`compatibility.json` 的 host_ref 记录最新实际通过集成验收的宿主提交；阅读馆 1.0.4 的宿主 0.3.3 历史基线保留在 [1.0.4 发布验收记录](reader-1.0.4-release.md)。后续若验证未提交改动，须另外记录真实 base SHA、dirty 状态和验证范围。
