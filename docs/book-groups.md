# 图书手动分组

图书 1.5.5 支持手动单分组：每本书最多加入一个分组。书库可切换全部分组、未分组和自定义分组，并与搜索、来源、格式和阅读状态共同筛选。分组按创建顺序展示，名称去除首尾空格后须为 1～40 字且不可重复。

在“管理分组”中可新建、改名、删除分组；删除须再次确认，组内书籍回到未分组，原文件与阅读记录保留。“批量分组”支持当前已加载页面全选和移动，切换筛选清空选择。详情页可以单独保存一本书的分组。保存失败保留已选书籍和目标分组，可重新加载后重试。

## 数据与兼容

- 分组存于应用存储 `library:book-groups`，独立于可清理的书库缓存，按稳定文件节点标识关联。改名、移动、重新扫描与暂时移除来源不清除归属。
- 分组定义与成员记录分别编码，使用 24 KiB 不可变分片，并以单一修订指针原子发布，满足宿主单条记录 32 KiB 的上限。分片失败或并发冲突不覆盖已发布快照。
- 跨页面更新比较实际存储修订号，避免将另一页面的连续写入误判为本地写入回流。弹窗内保留编辑内容，冲突时显式重新加载。
- 新建操作使用按钮事件及 Enter 键处理，兼容未开放 `allow-forms` 的应用沙箱。
- 沿用 API v2，无宿主 API、数据库迁移或网盘文件写入。共享阅读馆构建使漫画包更新至 1.3.8，漫画不显示图书分类入口。

## 本机容器维护

`docker compose build tgdrive` 因基础镜像仓库返回 HTTP 503 退出 1。本次只发布独立插件，宿主源码和镜像内容未变，最终执行 `docker compose up -d --no-build --force-recreate --no-deps --wait --wait-timeout 60 tgdrive`，退出 0，容器标识已改变且健康状态为 `healthy`。

重建复用现有镜像，未产生可清理的旧宿主镜像；为排查网络而下载的临时基础镜像和归档已清理。基础镜像仓库网络问题未通过修改项目配置绕过。
